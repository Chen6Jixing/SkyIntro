人们应该多抬头看看天空｜网站文件

打开方式：双击 index.html，或将整个 sky-listening-site 文件夹上传到任意静态网站托管服务。

文件说明：
- index.html：网页内容
- style.css：深蓝色响应式样式
- script.js：导航交互
- assets/voice-sample.m4a：提供的音频试听
- assets/portfolio-model.MOV：提供的个人风格视频

板评图片尚未包含在本次提供的素材中。板评区域目前显示待补图提示；收到图片后可放入 assets 并替换 index.html 中对应的占位区域。

说明：网页字体通过 Google Fonts 加载；如离线打开，系统会自动使用本地中文字体回退显示。
